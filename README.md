# Telecom C++ Tasks

Репозиторий содержит решения следующих тестовых заданий:

### 1. Моделирование работы производственного цеха:

* Реализована событийно-ориентированная симуляция работы цеха
* Логика основана на приоритетной очереди

### 2. Симуляция игрового бота для исследования подземелья:

* Реализован двухфазный алгоритм: исследование и возврат назад
* Используется BFS для навигации по графу
* Приложен файл `improvements.md` с моими мыслями о возможных оптимизациях

## Технологии

* **C++20**
* **CMake 3.25**
* **Clang-Tidy**
* **Clang-Format**

## Инструкция по сборке

Перейдите в директорию с необходимым заданием, после чего:

```bash
mkdir build
cd build
cmake -DCMAKE_BUILD_TYPE=Release ..
cmake --build .
```

## Использование

Приложения принимают путь к текстовому файлу с конфигурацией:

```bash
./FactorySimulation in.txt
```

```bash
./DungeonSimulation in.txt
```

## Замечания по поводу ТЗ

Во время решения заданий я заметил несостыковки в примерах.

1. ***Задача про подземелье:***
   В примере ответа итоговый счет ресурсов и их ценность кажутся некорректными относительно описанных правил сбора. Еще есть некоторые подозрения по поводу корректности входных данных, а именно по структуре графа....
2. ***Задача про цех:*** в пояснениях к примеру сказано, что 1-ый станок занят до `t=4`, во входном файле в матрице
   указано время обработки детали 1-го типа на 1-ом станке `t=6`
